The engineering underneath

Three things I built that were not on anyone's roadmap

A time machine for data

Source tables are overwritten continuously and native time travel keeps only days. I built a generic archive any table can join with one procedure call and a retention setting. It snapshots only on change, repairs itself when two jobs overlap, and returns data in the original layout.

Reports honest about failure

A four tier recovery model reconstructs a missing hour from the best surviving source and labels every recovered value with its origin, so leadership sees a complete report and knows exactly which numbers were rebuilt.

DataGINI

My own ingest and orchestration framework, roughly 10,000 lines of Python, sole author. Declarative YAML catalog, connectors rather than engine edits, parameter inheritance across job groups. Runs in production against ERP, commerce, loyalty, and legacy systems.

The problem I want to work on
